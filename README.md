## 研究链路

观察与历史 → 候选动作 → 预测后果 → 评价和选择 → 实际执行 → 记录反馈 → 适应或继续执行。

第一轮关注候选是否有改善空间、试探反馈是否可辨识、预测修正是否改善选择，以及直接历史策略是否已足够。
同状态分支用于离线诊断；在线试探后的状态变化和时间消耗必须计入任务。
